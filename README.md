# GOLEM

גוף פיזי ל‑AI: יצורים חיים על קיר LED, כל אחד עם אישיות, זיכרון וקול משלו.
רואים דרך מצלמה, שומעים דרך מיקרופון, מדברים דרך הרמקול, וחיים על פאנלים של
64×64 פיקסלים שמונעים ישירות מכרטיס הרשת של המחשב — בלי כרטיס שליחה ובלי LEDVISION.

הכל רץ **מקומית**. אין ענן ואין חשבונות.

---

## מה זה עושה

- **דמות לכל פאנל** — קלוד החמוד, חד השנון, נודניק העצבני, עצלן. לכל אחד
  פרומפט, קול וזיכרון פרטי משלו.
- **זיכרון פרטי** — מה שסיפרת לאחד לא ידוע לשני. אפשר לאפס לפני מסירה במתנה.
- **קול** — הקראה בעברית. מקוון לאיכות גבוהה, ונפילה אוטומטית למנוע המובנה של
  Windows כשאין רשת.
- **שמיעה** — תמלול עברית מקומי. מזהה מתי התחלת לדבר ומתי סיימת.
- **מדיה** — תמונות ואנימציות GIF לכל פאנל, עם עורך מיקום וגודל.
- **מצב קסם** — תנועה מול המצלמה מציירת על הקיר.
- **PARTY MODE** — סבב שיחה חי בין הדמויות, כל אחת מדברת מהפאנל שלה.
- **רשת חברתית** — הדמויות כותבות פוסטים ומגיבות זו לזו.

## התקנה

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python setup_wall.py
.venv\Scripts\python keepalive.py
```

ואז בדפדפן:

```
http://localhost:8765
```

`setup_wall.py` מגלה לבד על איזה כרטיס רשת הלוח מחובר — הוא מנסה גילוי אוטומטי,
ואם הכרטיס לא עונה הוא מדליק כל ממשק בתורו ושואל היכן הקיר נדלק.

### דרישות

- Windows, Python 3.11+
- [Npcap](https://npcap.com) במצב תאימות WinPcap — בלעדיו אין תקשורת עם הכרטיס
- כרטיס Colorlight 5A‑75B/75E ופאנלים HUB75
- אופציונלי: [Ollama](https://ollama.com) למוח מקומי, ומפתח OpenRouter לתשובות מהירות

---

## חומרה

| רכיב | תפקיד |
|---|---|
| Colorlight 5A‑75E | כרטיס קליטה, יציאות HUB75 |
| פאנלים 64×64 | הגוף של היצורים |
| ספק 5V | הזנה לפאנלים, בכבל נפרד לכל אחד |
| כרטיס רשת | שולח פריימים גולמיים בשכבה 2 ישירות לכרטיס |

**המיפוי אינו זהה בכל התקנה.** בהתקנה הזאת נמדד שכל יציאה מקבלת רצועת 64 שורות,
ובתוכה השרשרת נקראת מימין לשמאל. `wall_map.py` מתעד את מה שנמדד בפועל — אל תניח
שהמספרים נכונים ללוח שלך לפני שבדקת.

## מבנה

```
golem_live.py       מנוע הקיר. מצייר ושולח פריימים לכרטיס
golem_app.py        הממשק המקומי והשרת
keepalive.py        מפקח: מרים את התהליכים ומחזיר אותם אחרי נפילה
wall_map.py         מיפוי הפאנלים והיציאות
setup_wall.py       גילוי החומרה בהתקנה חדשה
senses/minds.py     אישיות, זיכרון ושרשרת מודלים
senses/voice.py     הקראה
senses/hearing.py   תמלול
senses/social.py    מסיבות ורשת חברתית
colorlight/driver.py  פריימי Ethernet גולמיים
```

## בדיקות

לכל רכיב יש בדיקה עצמית שרצה בלי חומרה:

```bash

.venv\Scripts\python golem_app.py --selftest
.venv\Scripts\python -m senses.minds --selftest
.venv\Scripts\python -m senses.social --selftest
.venv\Scripts\python -m senses.hearing --selftest
```

## סודות

מפתחות לא נכנסים לקוד ולא לגיט. המפתח נקרא מ‑`config/openrouter.key` או ממשתנה
הסביבה `OPENROUTER_API_KEY`, ושניהם מוחרגים ב‑`.gitignore`.

שמות המודלים החינמיים ב‑OpenRouter מתחלפים כל הזמן, ולכן המערכת מגלה בזמן ריצה
אילו זמינים במקום להסתמך על רשימה קבועה.
